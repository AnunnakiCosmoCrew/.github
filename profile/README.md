## 🛠️ What we're building

### ⏱️ SliceFocus
Plan your day on a **24-hour radial clock**, then focus through it with a built-in **Pomodoro**
timer that auto-advances from one block to the next. A Flutter app for iPhone, iPad, and Mac,
backed by a Spring Boot API on Google Cloud Run.

🌐 **[slicefocus.app](https://slicefocus.app)** · 📐 [Architecture & docs](https://github.com/AnunnakiCosmoCrew/slicefocus-docs)

### 🚗 ClearAhead!
A mobile traffic puzzle game — clear the road so an autonomous ambulance can reach the scene.
Built with **Flutter** and the **Flame** game engine.

### 🐦 Magpie
A lightweight, native **macOS clipboard manager**. Coming soon —
[⭐ star to follow](https://github.com/AnunnakiCosmoCrew/magpie).
